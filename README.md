## How to use

1. Install **Python** ([python.org/downloads](https://www.python.org/downloads/)) and **VS Code** ([code.visualstudio.com](https://code.visualstudio.com/)). Both are free.
2. Find the day you watched, for example [`python-in-60-days/day01-code/`](python-in-60-days/day01-code/).
3. Open `main.py` in VS Code and run it. Then change it and play with it. That is how you learn.

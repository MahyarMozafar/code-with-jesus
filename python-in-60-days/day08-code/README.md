## What it means

- A **method** is a ready-made tool for text: `upper()` all capitals, `title()` first letter big, `strip()` removes spaces at the ends.
- `len()` tells you how long the text is.
- Square brackets take a slice: `name[0]` is the first letter, `name[0:3]` the first three. Counting starts at **0**.

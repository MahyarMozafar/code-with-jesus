# Day 1: Your first code, a business card with `print()` and comments

- `main.py`: the card from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

Open the file in VS Code and press **Run** (the ▶ button at the top right), or type in the terminal:

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
+--------------------+
| Code with Jesus    |
| Python in 60 Days  |
| @codewithjesus     |
+--------------------+
```

## What it means

- `print()` shows text on the screen. Try it: `print("Hello world")` shows `Hello world`.
- Every `print()` prints **one line**.
- A line that starts with `#` is a **comment**. Python skips it. It is a note for you.

Print your own business card. Tip: make every line the same length, so the right edge is straight.

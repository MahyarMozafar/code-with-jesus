# Day 7: Type conversion: `int()` `float()` `str()`

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

It asks you a question in the terminal: type your answer and press Enter.

## What it means

- `int()` turns text into a whole number, so `age + 1` works now.
- `float()` turns text into a decimal.
- `str()` turns a number into text, so it can be joined with `+`.

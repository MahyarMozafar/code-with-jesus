# 🐍 Python in 60 Days

One short video every day: **one small idea + one small exercise**.
🛠 = mini project · 🏁 = final project

**How every day works**
- Each video starts by showing the finished result, then shows how it's made.
- Every piece of code is run before the video is posted, and its real output is shown on screen.
- Each day has its own folder: `day01-code/`, `day02-code/` … with `main.py` (the code from the video) and `exercise.py` (the answer to the day's exercise). Try the exercise yourself first!

**You need:** a computer, **Python** ([python.org/downloads](https://www.python.org/downloads/)) and **VS Code** ([code.visualstudio.com](https://code.visualstudio.com/)). Both are free.

# Day 3: Data types: `str` `int` `float` `bool` and `type()`

- `main.py`: the code from the video
- `exercise.py`: the answer to today's exercise (try it yourself first!)

## Run it

```bash
python main.py
```

(On Mac use `python3` instead of `python`.)

You should see:

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
<class 'str'>
<class 'float'>
```

## What it means

- Every value has a **type**: text is `str`, a whole number is `int`, a decimal is `float`, `True`/`False` is `bool`.
- `type()` tells you the type of a value.
- Anything in quotes is text (`str`), even `"25"`.
